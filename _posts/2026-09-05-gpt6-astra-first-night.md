3 号刷到 GPT-6 Astra 的时候，X 上已经开始复读「generational leap」。

我没赶上首波。Plus / Pro 放量是分批的，4 号白天模型列表里还没有，晚上才出现。时间线和 Wikipedia 后来说的「3 号预览、4 号对付费用户放开」对得上。我这种账号显然不在 limited org 里。

官宣里写 coding、research、computer use、多步任务。还特别提了能按模板吐文档、表格、PPT。听着像办公套件，不太像给我写 Vue 的。

## 第一晚我没让它碰仓库

就在网页里问了几个最近真实卡住的问题：

- GitHub Pages 构建绿了但站点还是旧的，可能卡在哪
- 嵌套仓库里 Source Control 为什么只认外层
- SSO 和 OAuth2 我该怎么跟面试官区分（别背定义，用项目说法）

它比 GPT-5.x 那一代更会「先复述你的现场」。  
比如会主动问你看没看 Actions，而不是直接甩一篇 Jekyll 教程。这点我喜欢。

computer use 我点开试了一下演示向的操作，慢，而且会停下来确认。现在更像能点按钮的助手，不像能替你值夜班的人。

## 翻车的地方

写东西爱铺排。让它「用三句话说完」，它还是会先来一段背景。

另外安全口径比以前紧。我随口问了个「如果签名算法被改了会怎样」这种排查向的问题，它先警告一堆，才回到前端该看哪个 header。能理解，尤其他们 safety overview 把 Astra 标到很高的网络安全能力档——发之前还因为 7 月那波 agent 出事推迟过。但对写业务代码的人来说，就是啰嗦。

额度也肉疼。网页里试两轮就提示用量。API 名是 `gpt-6-astra`，我还没往自己的脚本里接，先观望价格。

## 和 Fable 的第一印象差在哪

就第一晚：

- Astra 更像产品经理，爱给完整方案
- Fable / Claude Code 更像同事，直接去翻文件

还没法下结论。仓库级对比得等我在 Codex / Cursor 里各丢同一个任务。

3 号官宣当天 Altman 还为放量混乱道过歉，时间线上不少 Pro 用户进不去。这种发布节奏我已经免疫了：先别改默认模型，等周末自己的活跑一遍再说。
